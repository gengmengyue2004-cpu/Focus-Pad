Focus Pad v2 — 夜间界面预览

打开 app/index.html 即可预览；也可通过本地静态服务器访问。
默认展示夜间的娥眉月，时间 14:30 为预览初始状态。
顶部：日间 / 夜间 / 跟随时间。
组件右上角圆点：手动切换日间 / 夜间，日间进度球为渐变太阳。
手动切换后固定所选主题；点击顶部“跟随时间”恢复自动切换。
展开组件后可通过“任务专注 / 自由专注”按钮切换专注模式。
底部：切换月相，或选择当天月相。
自动时间：以电脑本地时间为准，21:00 至次日 06:00。
月相按平均朔望月估算，仅用于界面表现，不是精密天文历。
点击时间展开原有任务、计时和历史功能。
预览数据独立，不会读取或改写桌面原版记录。
此目录是独立预览，尚未合入 v2 桌面应用。
